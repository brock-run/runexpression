# Skills & Agents Maintenance Guide

This guide explains how to maintain and update RunExpression's AI skills and agents to stay in sync with Architectural Decision Records (ADRs) and project documentation.

## Overview

RunExpression uses:
- **Skills** (`.cursor/skills/`) - Specialized knowledge modules for specific domains
- **Agents** (`.cursor/agents/`) - Coordinated sets of skills for specific workflows
- **ADRs** (`docs/adr/`) - Architectural Decision Records documenting technical choices

Skills and agents should reference relevant ADRs to ensure they reflect current architectural decisions.

## Available Commands

### Sync ADRs to Skills/Agents

Sync ADR information into skills and agents:

```bash
# Preview changes (dry run)
npm run sync:adrs:dry

# Apply changes
npm run sync:adrs
```

This script:
- Reads all accepted ADRs from `docs/adr/`
- Injects ADR references into relevant skills/agents
- Adds "Related ADRs" sections with links

### Validate Skills/Agents

Check if skills and agents are up to date with ADRs:

```bash
npm run validate:skills
```

This script:
- Verifies all ADRs are referenced in appropriate skills/agents
- Reports missing references
- Suggests running `sync:adrs` to fix issues

### Sync Skills to Claude

Convert Cursor skills to Claude format:

```bash
npm run sync:skills
```

This copies skills from `.cursor/skills/` to `~/.claude/skills/` for use with Claude Code.

### List Skills/Agents

```bash
# List all skills
npm run skills:list

# List all agents
npm run agents:list
```

## Workflow

### When ADRs Change

1. **Update ADR file** in `docs/adr/`
2. **Run validation** to see what needs updating:
   ```bash
   npm run validate:skills
   ```
3. **Sync ADRs** to update skills/agents:
   ```bash
   npm run sync:adrs
   ```
4. **Review changes** in skills/agents
5. **Commit** both ADR and skill/agent updates together

### When Adding New Skills/Agents

1. **Create skill/agent file** in `.cursor/skills/` or `.cursor/agents/`
2. **Update ADR mappings** in `scripts/sync-adrs-to-skills.js` if needed
3. **Run sync** to add ADR references:
   ```bash
   npm run sync:adrs
   ```
4. **Sync to Claude** if needed:
   ```bash
   npm run sync:skills
   ```

### Regular Maintenance

Run validation periodically to ensure everything stays in sync:

```bash
npm run validate:skills
```

If issues are found, run sync to fix them:

```bash
npm run sync:adrs
```

## Skill Structure

Skills should include:

1. **YAML frontmatter** with name and description
2. **Overview** section
3. **Patterns and examples**
4. **Related ADRs** section (auto-generated by sync script)
5. **Related Documentation** links

Example:

```markdown
---
name: skill-name
description: Use when [triggering conditions]
---

# Skill Name

## Overview
Core principle in 1-2 sentences.

## Patterns
[Patterns and examples]

## Related ADRs
- [ADR-XXX: Title](../../docs/adr/xxx-title.md) - Summary

## Related Documentation
- **Guide**: `docs/XX-GUIDE.md`
```

## Agent Structure

Agents should include:

1. **YAML frontmatter** with name and description
2. **Primary Focus** section
3. **Core Responsibilities**
4. **Technical Standards**
5. **Key Skills to Apply**
6. **Related ADRs** section (auto-generated by sync script)

## Troubleshooting

### Sync script doesn't find ADRs

- Check that ADR files are in `docs/adr/` directory
- Verify ADR has `Status: Accepted` in frontmatter
- Ensure ADR follows the standard format

### Validation fails

- Run `npm run sync:adrs` to add missing references
- Check that ADR mappings in sync script are correct
- Verify skill/agent files exist in expected locations

### Skills not appearing in Claude

- Run `npm run sync:skills` to copy to Claude directory
- Check that skills have proper YAML frontmatter
- Verify `~/.claude/skills/` directory exists
